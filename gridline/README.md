# Gridline: Lab 1 (Core + Bonus, completed)

```bash
npm install
npm run dev
```

## What is inside

| Folder | Role |
| --- | --- |
| `src/services/` | The only place components get products and categories from |
| `src/utils/` | Pure helper functions: `formatPrice`, `cartHelpers`, `productFilters` |
| `src/features/cart/` | Redux Toolkit slice for the cart |
| `src/store/` | Redux store |
| `src/context/` | Theme context (light / dark) |
| `src/components/` | Reusable parts |
| `src/pages/` | `ShopPage`, the full screen |
